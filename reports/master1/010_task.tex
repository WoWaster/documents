\section{Постановка задачи}
\label{sec:task}

Целью работы является разработка встраиваемого предметно-ориентированного языка для описания учебных планов.
Для её выполнения были поставлены следующие задачи.
\begin{enumerate}
    \item Изучить структуру учебных планов СПбГУ.
    \item Реализовать eDSL, базирующийся на семестрах.
    \item Реализовать экспорт в Office Open XML Workbook.
\end{enumerate}
