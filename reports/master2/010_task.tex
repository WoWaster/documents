\section{Постановка задачи}
\label{sec:task}

Целью настоящей работы является реорганизация инфраструктуры для измерения производительности графовых алгоритмов на основе взаимодействующих сетей.

Для достижения поставленной цели были решены следующие задачи:
\begin{enumerate}
    \item Перейти от набора разрозненных скриптов к единому интерфейсу командной строки для запуска этапов измерений~(раздел~\ref{subsec:cli}).
    \item Выделить общие модули, обеспечивающие единый способ настройки, запуска измерений и сбора результатов~(раздел~\ref{subsec:common}).
    \item Упростить добавление новых инструментов, описав единые правила их подключения~(раздел~\ref{subsec:integration}).
    \item Обеспечить воспроизводимость экспериментов за счёт единого файла настроек и автоматизации работы с матрицами~(раздел~\ref{subsec:matrixwork}).
    \item Проверить работоспособность реорганизованной инфраструктуры на имеющемся наборе инструментов~(раздел~\ref{sec:experiment}).
\end{enumerate}
